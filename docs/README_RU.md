# 🚀 Lumina: Универсальный ИИ-помощник (RAG + MCP + Agent)

**`Lumina` — это мощный универсальный плагин-помощник для Obsidian, который превращает вашу базу знаний в полноценный ИИ-хаб, объединяя поддержку нескольких LLM, RAG без сложных настроек, двустороннюю интеграцию MCP и автономных ИИ-агентов.**

## 🌟 Основные возможности

| Функция | Описание |
| :--- | :--- |
| **💬 Мульти-LLM Чат** | Специальная боковая панель, понимающая контекст ваших заметок. Поддерживает всё: от мощных облачных моделей до локальных LLM для максимальной конфиденциальности. |
| **🧠 RAG без настроек** | Включает 100% автономные локальные эмбеддинги для предотвращения утечки данных. Автоматически индексирует ваше хранилище в реальном времени без сложных конфигураций. |
| **⚡ Быстрые действия ИИ в редакторе** | Выделите текст в редакторе, чтобы мгновенно обобщить, перевести или проверить его, не прерывая процесс написания. |
| **🤖 Автономный ИИ-агент** | LLM автономно планируют и выполняют сложные задачи, такие как поиск, создание и изменение заметок с использованием инструментов MCP. (Экспериментально) |
| **🔌 Интеграция MCP (Клиент и Сервер)** | Двусторонняя полнофункциональная интеграция, позволяющая использовать внешние инструменты внутри Obsidian (Клиент) или позволять внешнему ИИ взаимодействовать с вашими заметками (Сервер). (Экспериментально) |

## ⚡ Быстрый старт

1. **Установите** и включите `Lumina` из раздела плагинов сообщества Obsidian.
2. После включения встроенная модель RAG автоматически начнет анализ ваших заметок в фоновом режиме. (В боковой панели станет доступна умная навигация).
3. **[Включение ИИ Чата]** Перейдите в Настройки Obsidian ➔ `Lumina`.
4. Добавьте предпочитаемого провайдера LLM и введите ваши API-ключи.
   - 💻 **Локальные LLM (Ollama, LM Studio и др.)** можно подключить мгновенно без API-ключей!
   - ☁️ **Облачные LLM** требуют API-ключи, которые легко получить бесплатно:
     - 👉 [Получить API-ключ Google Gemini (Бесплатно)](https://aistudio.google.com/app/apikey)
     - 👉 [Получить API-ключ Groq (Бесплатно)](https://console.groq.com/keys)
5. **[Открытие чата и базовое использование]** Нажмите значок 💬 в левом боковом меню, чтобы открыть панель чата и начать общение с ИИ, или выделите текст в редакторе и щелкните правой кнопкой мыши для запуска быстрых действий.
6. **[Включение режима агента]** Введите команду `/mcp` в чате или откройте всплывающее меню для активации **🤖 Режима агента**.
   - *Совет: Внутренний сервер Lumina, необходимый для автономной работы агента, автоматически запустится в фоновом режиме.*
7. **Постановка автономных задач:** При активном Режиме агента дайте сложную инструкцию, например: "Найди все заметки, связанные с 'Искусственным интеллектом' в моем хранилище, обобщи ключевые моменты и организуй их в новую заметку." ИИ автономно определит и выполнит необходимые инструменты для завершения задачи.

> [!IMPORTANT]
> **🔒 Безопасное хранение API-ключей**
> Все введенные вами API-ключи никогда не сохраняются в виде обычных текстовых файлов. Они надежно зашифрованы и хранятся локально через встроенное в Obsidian хранилище `SecretStorage`, обеспечивая безопасность ваших данных.

## ✨ Подробные функции и использование (Нажмите, чтобы развернуть)

<details>
<summary><b>💬 Мульти-LLM Чат (Поддержка облачных и локальных LLM)</b></summary>

- **Описание:** Мгновенно общайтесь с различными ИИ-моделями через специальную боковую панель внутри Obsidian. Полностью поддерживает мощные облачные модели, такие как Gemini и Groq, а также **Локальные LLM** (Ollama, LM Studio и др.) для абсолютной конфиденциальности.
- **Как использовать:** Нажмите на значок 💬 на левой панели или выполните `Lumina: Open Chat` из палитры команд.
- **💡 Профессиональный совет:** Выделите текст в редакторе, щелкните правой кнопкой мыши и используйте контекстное меню, чтобы напрямую передать выбранный текст в чат в качестве контекста для ваших вопросов!
</details>

<details>
<summary><b>🧠 Чат на базе RAG и локальные эмбеддинги (Абсолютная конфиденциальность)</b></summary>

- **Описание:** ИИ получает глубокое понимание вашей базы знаний. Он автономно ищет релевантные заметки во время разговоров и отображает похожие документы и рекомендуемые теги в боковой панели, создавая умные контекстные связи.
- **Оффлайн-безопасность:** Встроенная поддержка локальных эмбеддингов (`ibm-granite`). Если не выбрана облачная модель, ценные данные ваших заметок никогда не покинут ваше устройство. *(⚠️ Локальные эмбеддинги не поддерживаются на мобильных устройствах).*
- **Полная автоматизация:** Никаких настроек не требуется! Фоновая индексация незаметно начинается в момент включения плагина и автоматически синхронизируется в реальном времени (режим `watch`) при любом изменении заметок.
</details>

<details>
<summary><b>⚡ Встроенный ИИ в редакторе (Быстрые действия)</b></summary>

- **Описание:** Мгновенно преобразуйте текст в редакторе Markdown, не прерывая процесс написания. Легко справляйтесь с переводом, обобщением, исправлением грамматики и подробными объяснениями для выделенного текста.
- **Как использовать:** Выделите текст и выполните быстрые действия через всплывающее меню или палитру команд. *(💡 Совет: Назначьте горячие клавиши в настройках Obsidian для сверхбыстрого доступа!)*
</details>

<details>
<summary><b>🤖 Автономный ИИ-агент (Режим агента) ⚠️</b></summary>

- **Описание:** При активации LLM автономно определяет и организует инструменты MCP для выполнения задач. Он может завершать сложные многоступенчатые операции, комбинируя поиск, чтение, запись заметок и извлечение RAG.
- **Поддержка локальных LLM:** Реализован специальный парсер, поддерживающий текстовые подсказки для инструментов, что позволяет агенту бесперебойно работать даже в среде локальных LLM, а не только с высокопроизводительными облачными моделями.
- **Механизмы безопасности:** Для предотвращения бесконечных циклов или чрезмерных затрат на API введено ограничение максимального количества шагов выполнения на один запрос (по умолчанию: 15 шагов). Выполнение автоматически прерывается при обнаружении повторяющихся вызовов инструментов.
- **Как использовать:** Введите команду `/mcp` в чате или используйте верхний значок, чтобы открыть быстрое всплывающее окно и включить 'Режим агента'. (Внутренний сервер Lumina автоматически запустится при необходимости для выполнения инструментов).
</details>

<details>
<summary><b>🤖 Интеграция MCP (Двусторонняя поддержка клиента и сервера) ⚠️</b></summary>

- **Описание:** Бесшовно соединяет Obsidian с более широкой экосистемой ИИ через протокол контекста модели (MCP). Используйте Obsidian как универсальный ИИ-хаб или применяйте его как второй мозг вашего ИИ!
- **💻 Режим клиента (Управляется Obsidian):**
  - Взаимодействуйте и работайте напрямую с ИИ внутри Obsidian.
  - Подключайте множество внешних серверов MCP (GitHub, локальные БД, веб-поиск и т.д.) для мгновенного сбора и организации огромных объемов данных в ваших заметках.
- **🖥️ Режим сервера (Управляется внешним ИИ):**
  - Предоставляет 7 инструментов, позволяющих внешним ИИ-помощникам (Claude, Cursor и др.) напрямую получать доступ к вашему хранилищу.
  - `read_active_note`, `read_note`, `search_notes`, `rag_search`: Предоставляет контекст и знания вашего хранилища для ИИ.
  - `create_note`, `append_to_note`: Позволяет ИИ безопасно записывать организованные идеи напрямую в ваше хранилище (применяется защита от перезаписи).
  - `read_daily_note`, `append_to_daily_note`: Интеграция чтения/записи для сегодняшней ежедневной заметки.
- **Как использовать:** Включите функции MCP в настройках плагина и настройте методы транспортировки клиент/сервер (SSE).
- **Примечание:** *Функции агента и MCP в настоящее время находятся на стадии тестирования (Beta). Несмотря на наличие различных систем безопасности, таких как защита от перезаписи и ограничения количества символов, мы рекомендуем поначалу внимательно следить за операциями, поскольку внешний ИИ будет напрямую редактировать ваши заметки.*
</details>

## 🐛 Режим отладки и отчеты об ошибках

Вы можете просматривать все внутренние данные, обрабатываемые плагином, включив Расширенные настройки и активировав [Режим отладки] на вкладке [Дополнения и Разное] в настройках. (Журналы отладки не сохраняются до их загрузки).

**💡 Полезная информация для решения проблем:**
- Ваше Устройство/ОС (ПК / Моб. телефон) и версия Obsidian.
- ИИ-провайдер и имя используемой модели (например, OpenAI / gpt-4o, Ollama / llama3).
- Файл журнала, скачанный после возникновения ошибки в Режиме отладки.
> [!IMPORTANT]
> Поскольку файлы журналов могут содержать расшифровки чатов, пожалуйста, удалите любую конфиденциальную информацию перед отправкой.
> **[Сообщить об ошибке (GitHub Issues)](https://github.com/lumina-apps/obsidian-lumina/issues)**
